## 2. 按需求明确排除

- 不加载插件类功能（OBS / vMix / YouTube / 第三方插件）。
- 不加载动画与背景动画。
- 不加载旋钮 RGB。
- 不使用任何网络端口（18618 等）。
- 不修改用户配置（只读）。
- 不提供 UI 配置界面，仅日志窗口 + 托盘。

## 4. 已验证的关键结论（勿再重复试错）

- 设备厂商集合：VID `0x5548` / PID `0x1008` / usage_page `0xFFA0` / usage 1。
- OUT 1025B / IN 513B，ReportID 首字节。
- 图像槽位：触摸条 `1~4`、下排按键 `6~10`、上排按键 `11~15`，槽位 `5` 未使用。
- 按键图像 112×112、触摸条 800×130、发送前 180°。
- Control Bar 为单张 800×130 虚拟长图 + 滚动偏移，不是多图拼接。
- 命中公式：`index = (X + scroll - 25) / 152`。
- 退出帧：`CLE` + `"DC"`，在 `hid_close` 前发送。
- 旋钮编码：1=`A0/A1`、2=`50/51`、3=`90/91`、4=`70/71`；按下 `37/35/33/36`。
- 模式切换：`0xB1` 旋钮 / `0xB2` Control Bar。
- 场景必须按 `DeviceUUID` 过滤。
- 官方缩放：KeepAspectRatio + Smooth + 居中，不裁剪，小图也放大。
- 字号：`pt × 1.2`。
- 按键配置位置：上排 `y2`、下排 `y1`，与图像槽位分开映射。
- Win32 EDIT 控件需要 CRLF 换行。

## 6. 给新项目的建议顺序

1. 先做 HID 最小回环（DIS/LIG/CLE/BAT/STP）。
2. 再做按键图像与索引映射。
3. 再做 ini → 场景 → 页面 → 动作表。
4. 再做触摸条两种模式与命中。
5. 再做动作执行器（热键/鼠标/多动作）。
6. 最后做退出帧、重连、托盘与日志窗口。

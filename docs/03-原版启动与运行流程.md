# 03 · 原版软件启动与运行流程

> 对象：`C:\Program Files (x86)\StreamDock\StreamDock.exe`（HotSpot StreamDock）
> 本文记录官方进程模型、启动顺序、设备会话与关闭流程，供重制版对齐。

## 1. 进程模型

| 进程 | 作用 |
|---|---|
| `StreamDock.exe` | 主程序（Qt）：界面、配置、HID、渲染、动作调度 |
| `CefViewWing.exe` | 内嵌浏览器宿主（插件 UI / Web 内容） |
| `node20.exe`（若干） | 插件运行时进程 |
| `SplashScreen.exe` | 启动闪屏 |

- 主程序退出时并非所有子进程都会立即消失；重制版不需要这些进程。
- 端口 **18618** 是插件 WebSocket 通信端口（主程序 ↔ 插件），**不是设备协议端口**，重制版不使用任何端口。

## 2. 启动顺序（逆向确认）

```
SplashScreen 显示
  → StreamDock.exe 初始化 Qt
  → 读取 StreamDock.ini（设备型号 / 序列号 / 场景路径）
  → 枚举 HID 设备，打开厂商集合
  → 读取当前场景 manifest
  → 读取 Pages.Current，定位当前页
  → 加载页面动作表与图片资源
  → 初始化触摸条模式（Control Bar / 旋钮）
  → 首帧整页刷新（CLE → 触摸条 → 按键 → SETLB → STP）
  → 发送 CONNECT
  → 进入输入事件循环
```

关键行为：

- 启动时按 ini 记忆的设备与场景加载，因此“官方软件退出时的场景页”会被原样恢复。
- 启动阶段会读取设备亮度、旋转、触摸条模式。
- 首帧刷新是**整页**，不是逐键。

## 3. 设备会话

### 3.1 打开

- 枚举 HID 接口，匹配 VID `0x5548` / PID `0x1008` / usage_page `0xFFA0` / usage 1。
- 键盘/鼠标子集合（`mi_00`、`mi_01`）打开失败属正常，应忽略。
- 打开后设置较大的输入缓冲（官方行为），并使用重叠 I/O。

### 3.2 关闭（关键）

`SDDevice::closeHidDevice` 的调用链：

```
closeHidDevice
  → sendDisconnectCommand
      → 构造 CRT + CLE + 参数 "DC"
      → 写入 1025 字节
  → hid_close
```

- 参数 `"DC"` 位于载荷偏移 11/12（帧偏移 12/13）。
- 发送后建议等待 100~250ms 再关闭句柄。
- 官方正常退出不会让设备进入异常态；直接 `hid_close` 会。

## 4. 画面与分层

官方把“背景层 / 图标层 / 文字层”分开处理：

| 层 | 命令 | 说明 |
|---|---|---|
| 背景层 | `BGPIC` / `BGCLE` | 触摸条 800×130 背景图；Control Bar 模式使用 |
| 图标层 | `BAT` | 按键 112×112；触摸条分区图 |
| 文字层 | 无独立命令 | 文字被绘制进图标/背景 PNG 后再下发 |

- 文字不是设备端字体，而是**主机侧 GDI 绘制后编码进 PNG**。
- 因此字体、字号、颜色、换行都由主机决定（见 04 文档）。
- 刷新顺序：`CLE` → 触摸条 → 按键 → `SETLB` → `STP`；背景图 `BGPIC` 会覆盖按键层，只能在 Control Bar 场景使用。

## 5. 输入处理

```
HID 读线程（阻塞/重叠）
  → 解析 ACK / ARX 报文
  → 按键 idx + state
  → 触摸坐标
  → 旋钮旋转/按下
  → 模式切换
  → 分发到当前页动作表
```

- 按键按下不重绘按键图。
- 触摸滑动只刷新触摸条。
- 切页才整页重绘。
- 旋钮旋转只转发动作，不重绘触摸条（官方 `SDActionCanvasLabel::dialRotate` 行为）。

## 6. 渲染与下发

1. 读取动作状态图 / 图标。
2. 按目标尺寸等比缩放并居中（官方 `getFixedProportionImage`，地址 `0x1401223D0`）。
3. 叠加文字层（字号 `pt × 1.2`）。
4. PNG 编码。
5. 按 1024 字节分片写入 HID。
6. 组尾 `SETLB` + `STP`。

- 官方对整页刷新会一次性下发全部图，实测 177~385 帧。
- 触摸条 Control Bar 是“单张 800×130 虚拟长图”，滚动通过偏移实现，而不是多张图拼接。

## 7. 官方关闭与退出

- 主窗口关闭：保存当前场景/页 → 关闭 HID（发送 `CLE+DC`）→ 退出子进程。
- 退出后会保留 ini 中的场景路径，因此下次启动恢复同一场景。
- 官方没有“最小化到托盘”的重制版需求，但托盘行为不影响 HID。

## 8. 重制版对应的实现顺序（0.6.x）

```
解析参数 → 初始化日志（默认无控制台）→ 初始化 GUI 日志窗口 + 托盘
→ 单实例互斥 → 读取 ini → 读取场景/页面 → 打开 HID
→ 打开失败：进入 USB 等待模式（不退出）
→ 成功：DIS → LIG → 整页刷新 → CONNECT
→ 输入循环；2 秒 RGBS 心跳
→ 托盘“退出”：CLE+DC → 关闭句柄 → 结束进程
```

## 9. 证据与函数参考

| 符号/地址 | 说明 |
|---|---|
| `SDDevice::closeHidDevice` | 关闭设备并发送断开命令 |
| `sendDisconnectCommand` | 构造 `CRT CLE + "DC"` |
| `SDActionCanvasLabel::getFixedProportionImage`（`0x1401223D0`） | 等比缩放 + 居中 |
| `SDActionCanvasLabel::dialRotate` | 旋钮旋转只转发动作 |
| `SDActionTouchBarWidget::getTouchbarLoactionFromX`（`0x1401A8210`） | Control Bar 命中计算 |
| `updateN4ProTouchBarBackground` | 800×130 背景常量（0x320 / 0x82） |

> 更完整的符号与调用链见 `docs/evidence/` 与 `docs/StreamDock逆向分析报告.md`。

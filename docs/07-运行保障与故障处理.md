# 07 · 运行保障、退出与故障处理

> 本文汇总重制版的运行形态、退出/重连策略、已知问题与调试手段，便于新项目复用。

## 1. 运行形态

| 模式 | 启动方式 | 行为 |
|---|---|---|
| 默认（GUI） | 双击 exe | 无控制台；隐藏日志窗口 + 托盘图标 |
| `-serve` | 命令行 | 静默后台，无窗口无托盘；日志仅内存 |
| `--console` | 命令行 | 附加父控制台或新建控制台，日志同步输出 |
| `--once` / `--probe` | 调试 | 执行一次初始化/探测后退出 |

- release 构建为 `windows_subsystem = "windows"`，**不创建 conhost 控制台窗口**。
- 这样彻底规避 Win11“隐藏控制台后任务栏残留图标”的问题。

## 2. 日志窗口与托盘

- 日志窗口：只读多行文本，深色背景，Consolas。
- 固定 **50 行**环形缓冲，超出自动滚掉，不占内存。
- Win32 EDIT 控件只识别 **CRLF**，写入前必须把 `\n` 转成 `\r\n`，否则日志挤成一行。
- 行为：
  - 启动隐藏，仅托盘可见；
  - 双击托盘 → 显示并置前；
  - 最小化 / 点 X → 隐藏（不退出）；
  - 托盘右键 → 显示日志 / 退出。
- 日志不写文件；如需长期留存，复制窗口文本即可。

## 3. 退出流程（关键）

```
托盘右键“退出”
  → 停止图像写入（置 EXITING）
  → 直接写 CLE + "DC"（不排队）
  → 等待约 100~250ms
  → 关闭 HID 句柄
  → 进程退出
```

- **只有托盘“退出”与系统注销/关机才真正结束软件。**
- 关闭日志窗口、最小化、Ctrl+C 均不退出。
- 任务管理器强杀无法发送结束帧，设备可能停在异常态，需要重新插拔。

## 4. USB 断连与自动重连

触发条件：

- `CreateFile` 失败；
- 读错误 `1167`（设备未连接）、`1784`；
- 写错误。

处理流程：

```
停止写线程 → 丢弃句柄 → 结束会话
→ 进入 USB 等待模式
   - 隐藏窗口 + RegisterDeviceNotificationW(WM_DEVICECHANGE)
   - 2 秒兜底探测
   - 阻塞等待，CPU ≈ 0
→ 检测到设备接入
→ 重新打开 → DIS/LIG/整页刷新/CONNECT
→ 恢复输入循环
```

- 启动时设备不在线也进入等待模式，**不退出进程**。
- 等待期间不要重试打开设备（避免占用 CPU）。

## 5. 单实例

- 互斥体名：`Local\N4ProCore_SingleInstance`。
- 已存在实例时最多等待约 6 秒（20 × 300ms），等旧实例退出后接管。
- 用于兼容“关闭窗口后重启到托盘”的旧方案；0.6.x 已不需要重启。

## 6. 性能策略

| 场景 | 策略 |
|---|---|
| HID 读 | 阻塞读线程，无轮询 |
| HID 写 | 单写线程 + 有界队列 |
| 整页刷新 | 按批次入队，丢弃过期批次，只发最新页 |
| 图像分片 | 连续发送，帧间 0ms |
| 触摸条滑动 | 仅一张 800×130，30~60ms 节流 |
| 按键按下 | 不重绘 |
| 切页 | 整页重绘一次 |
| 日志 | 内存环形 50 行 + UI 定时批量刷新（100ms） |
| 心跳 | 2 秒 `RGBS` |
| USB 等待 | 事件驱动，无忙循环 |

## 7. 已知问题与处理

| 问题 | 根因 | 处理 |
|---|---|---|
| 关闭后 USB 异常、需插拔 | 未发送结束帧 | 退出前 `CLE + "DC"` |
| 反复开关后无响应/延迟 | 主线程被控制台输出阻塞 | 控制台输出独立线程/有界队列；0.6 起改 GUI |
| 按键/旋钮“无响应”一分钟 | 控制台 QuickEdit 阻塞 | 同上，日志改内存+窗口 |
| 快速切页后画面落后几十秒 | 写队列无上限、不合并 | 整页批次合并，只发最新 |
| 托盘恢复后任务栏残留 | conhost 行为 | 0.6 起无控制台窗口，彻底规避 |
| 场景切换后旋钮“未绑定” | 加载了其它设备的空场景 | 按 `DeviceUUID` 过滤场景 |
| 旋钮方向反了 | 方向位归一化错误 | `+1/-1` 归一化 |
| 组合键在游戏中无效 | 无扫描码/无间隔 | 扫描码 SendInput + 15~18ms |
| 只发左 Ctrl 不走右 Ctrl | 未读 `RKey*` 且 Alt 读错字段 | 左右修饰键分别发送，Alt 读 `KeyOption` |
| 小图标显示过小/黑边 | 跳过放大 | 小图也等比放大 |
| 图标变形 | cover 铺满裁剪 | 等比 contain 居中 |
| 日志挤成一行 | EDIT 只识别 CRLF | LF → CRLF |
| 设备偶发消失 | 线材/USB 口/供电，官方同样出现 | 等待重连；必要时换线换口 |

## 8. 调试参数

| 参数 | 作用 |
|---|---|
| `-serve` | 静默后台 |
| `--console` | 附加/新建控制台输出日志 |
| `--dry-run` | 动作只记录不执行 |
| `--log-input` | 打印原始输入帧 |
| `--dump-frames` | 帧转储到文件 |
| `--no-device` | 不打开设备（离线验证） |
| `--once` | 初始化一次后退出 |
| `--probe` | 仅发 DIS + LIG |
| `--profile <path>` | 指定场景路径 |
| `--mode knob\|bar` | 强制触摸条模式 |
| `--no-bgpic` | 不发送背景图 |

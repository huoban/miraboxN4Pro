# N4ProCore 阶段总结（2026-11-13）

## 1. 阶段目标与结论

本阶段完成了 StreamDock.exe 的逆向分析，并交付了可运行的 Rust 重制版 **0.2.0**。
实机结果：**10 个物理按键显示正常，全部触控/按键/旋钮输入响应正常**；触摸条部分 UI 显示不正确，待原图与对比图后修正。

## 2. 已完成内容

### 2.1 逆向分析
- 恢复 67,414 个函数、593 个类（PDB 私有符号）。
- 确认进程模型：主进程 + CEF + 每插件一个 `node20.exe`；18618 为插件 WebSocket，不是私有 TCP。
- 实测 HID：`VID 0x5548 / PID 0x1008 / usage_page 0xFFA0 / usage 1`，OUT 1025B、IN 513B。
- 还原输出协议：`00 + "CRT" 00 00 + 命令 + 参数`，PNG 按 1024B 分片；命令含 `DIS/LIG/LBLIG/QUCMD/BGCLE/BGPIC/BAT/CLE/SETLB/STP/CONNECT/RGBS`。
- 还原输入协议：`ACK 00 00 OK 00 00 idx state`、`ACK 00 ARX ... x/y`、`0xA1..` 旋钮、`0x37..` 按下、`0xB1/0xB2` 模式切换。
- 槽位实测：按键 6~15、触摸条 1~4（1~4 显示在触控区）。
- 证据与报告：`docs/StreamDock逆向分析报告.md`、`docs/evidence/`。

### 2.2 Rust 工程（0.2.0）
- 单 exe、无 UI；默认控制台，`-serve` 静默后台（FreeConsole）。
- 只读配置：ini → 场景 manifest → `Pages.Current` → 子页面动作。
- HID：Overlapped I/O 单句柄、2 秒 RGBS 心跳、写入节流（分片 5ms / 图片间 60ms）。
- 渲染：按键 112×112、触摸条 4×176×112，GDI 文字，PNG 编码，发送前旋转 180°。
- 输入：按键 1~10、旋钮旋转/按下、触摸坐标、0xB1/0xB2 模式切换。
- 动作执行器：热键、打开、网址、多媒体/音量、翻页、场景切换、多动作/延时、HTTP、UDP/OSC、本地脚本；插件类动作记录后跳过。
- 日志：exe 运行目录 `logs\n4pro.log`，2MB×3 滚动。
- 单元测试：8/8 通过（协议帧、输入解析、INI 解析）。

## 4. 已知问题（下一阶段）

1. 触摸条 UI 布局/内容与官方不一致（等待用户提供原图与对比图后修正）。
2. 左右滑动翻页后触摸条未重新刷新（BGPIC 协议未接入）。
3. Control Bar 快捷点击码 `0x40~0x43` 未映射到子动作。
4. 设备长时间运行偶发掉线，需硬件与心跳策略排查。
5. 高 DPI/字体差异可能带来 1~2px 文字偏移。

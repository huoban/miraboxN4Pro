## 关键常量速查

| 项目 | 值 |
|---|---|
| VID / PID | `0x5548` / `0x1008` |
| Usage Page / Usage | `0xFFA0` / `1` |
| 输出 / 输入报文 | `1025 B` / `513 B` |
| 帧头 | `00 43 52 54 00 00`（ReportID + `CRT`） |
| 按键图 | `112 × 112`，上排 `11~15` / 下排 `6~10` |
| 触摸条图 | `800 × 130`，`BGPIC` |
| 图像旋转 | 发送前 180° |
| 按键配置坐标 | 上排 `y=2`，下排 `y=1` |
| 旋钮配置坐标 | `"0,0"`~`"3,0"` |
| Control Bar 条目 | `142 × 66`，Y=42，步长 152，起点 25 |
| 触摸命中 | `(X + scroll − 25) / 152` |
| 退出帧 | `CLE` + `"DC"` |
| 心跳 | `RGBS`，2 秒 |
| 字号 | `pt × 1.2` |

## 十条最容易踩坑的规则

1. 上排按键图像写槽位 `11~15`、下排写 `6~10`；图像槽位与配置坐标是两套编号。
2. 上排按键读配置 `y2`，下排读 `y1`；图像槽位与动作位置必须分开映射。
3. 所有图像发送前旋转 180°。
4. 图标缩放用等比完整放入并居中；小图也要放大，不裁剪。
5. Control Bar 是单张 800×130 虚拟长图 + 滚动偏移。
6. 场景必须按 `DeviceUUID` 过滤，否则会切到其它设备的空场景。
7. 退出前必须发 `CLE + "DC"`，否则设备会进入 USB 异常态。
8. 热键用扫描码发送，并区分左右修饰键；Alt 在 `KeyOption`。
9. 多动作的 `Settings.delay` 是子动作执行前的等待时间。
10. 日志窗口文本必须用 CRLF；Win32 EDIT 不识别纯 LF。

# 02 · 配置体系与场景模板

> 官方配置全部只读；重制版不修改任何用户配置。
> 路径基于 Windows 当前用户 `%APPDATA%\HotSpot\StreamDock`。

## 1. 目录结构

```
%APPDATA%\HotSpot\StreamDock\
├── StreamDock.ini                 # 全局配置（设备、当前场景等）
├── profiles\
│   ├── <场景UUID>.sdProfile\       # 一个场景（Scene）
│   │   ├── manifest.json           # 场景根页配置
│   │   ├── *.png / *.gif / *.jpg   # 根页图片资源
│   │   └── profiles\
│   │       └── <页面UUID>.sdProfile\
│   │           ├── manifest.json   # 子页面配置
│   │           └── *.png ...
│   └── ...                         # 可能包含其它型号设备的场景
└── ...
```

- 一个设备可能对应多个场景；`profiles` 目录中会混有其它设备（如 `StreamDock[293S]`）的场景。
- 场景目录本身就是一个页面；子页面位于其 `profiles\<页面UUID>.sdProfile` 下。

## 2. ini 加载链（已确认）

```
StreamDock.ini
  → 设备型号 / 设备序列号（如 49490078391A）
  → 当前场景路径 sdProfilePath
  → 场景 manifest.json
  → Pages.Current 定位当前页
  → 若当前页 != 场景根页，读取 profiles/<页面UUID>.sdProfile/manifest.json
```

- 重制版只读取，不写回。
- ini 的具体键名以实现代码 `src/config/mod.rs` 为准；不同版本官方可能调整键名。
- 启动日志会打印：设备型号、序列号、场景路径、亮度、旋转、触摸条模式。

## 3. 场景 manifest（根页 / 子页通用）

关键字段：

| 字段 | 类型 | 说明 |
|---|---|---|
| `Name` | string | 页面/场景显示名，如 `游戏`、`监控` |
| `DeviceUUID` | string | 所属设备型号标识，用于场景过滤 |
| `DeviceSerialNumber` | string | 所属设备序列号 |
| `Pages` | string[] | 子页面 UUID 列表；根页场景也包含自身或页面列表 |
| `Current` | string | 当前页 UUID |
| `Actions` | object | 动作表，键为 `"x,y"` |
| `Actions["touchbar"]` | object | 触摸条配置（滚动位置等） |

示例（结构示意）：

```json
{
  "Name": "游戏",
  "DeviceUUID": "456AXNQI-J9YD-V2GQ-Y4WV-1FCOB43037M7",
  "DeviceSerialNumber": "49490078391A",
  "Pages": ["1JH7D037-N4NO-2974-YN37-ZHEOMJ8S2Y68", "..."],
  "Current": "1JH7D037-N4NO-2974-YN37-ZHEOMJ8S2Y68",
  "Actions": {
    "0,0": { "UUID": "com.hotspot.streamdock.profile.rotate", "Name": "Scene Shift", "Settings": {} },
    "0,1": { "UUID": "com.hotspot.streamdock.hotkey", "Name": "左Ctrl+F10", "Settings": { "...": "..." } },
    "0,2": { "UUID": "com.hotspot.streamdock.multiactions", "Name": "鼠标宏", "Actions": [ ... ] },
    "touchbar": { "Settings": { "widgetCurrX": -152 } }
  }
}
```

- `Actions` 的键 `"x,y"`：
  - `x` = 0~4，左→右。
  - `y` = 1 底排，2 上排（与物理按键的对应关系见 06 文档）。
  - 旋钮使用第 0 行的 `"0,0"`~`"3,0"`（左起旋钮 1~4）。
- `Actions["touchbar"].Settings.widgetCurrX`：Control Bar 横向滚动偏移，**负值**；启动时恢复。

## 4. 动作节点结构

### 4.1 普通动作

```json
{
  "UUID": "com.hotspot.streamdock.hotkey",
  "Name": "左Ctrl+F10",
  "Settings": { "...": "..." },
  "States": { "...": "..." }
}
```

- `UUID` 决定动作类型（见 05 文档）。
- `Settings` 为动作参数，字段随 UUID 变化。
- `States` 存放各状态对应的图片/标题等资源引用（不同版本字段名略有差异）。

### 4.2 多动作（操作流）

```json
{
  "UUID": "com.hotspot.streamdock.multiactions",
  "Name": "鼠标宏",
  "Settings": {
    "enablingCycle": false,
    "cycleMode": 0,
    "cycleNumber": 1,
    "cycleDelay": 0
  },
  "Actions": [
    { "UUID": "...", "Settings": { "delay": 800 } },
    { "UUID": "...", "Settings": { "delay": 1000 } },
    { "UUID": "...", "Settings": { "delay": 230000 } }
  ]
}
```

- 子动作位于父动作的 `Actions` 数组。
- **每个子动作的 `Settings.delay` 表示执行该子动作前的等待毫秒数**（实测：800 / 1000 / 230000）。
- 多动作可嵌套；实现需设置递归深度上限。

## 5. 场景过滤规则（重要）

**官方按 `DeviceUUID` / `DeviceSerialNumber` 过滤场景，而不是加载 `profiles` 下全部目录。**

- 实测某机器 `profiles` 下有 30 个 `.sdProfile`，其中 27 个属于 `StreamDock[293S]`（23 个空场景 + 信息看板/常用网站/音乐控制台等），仅 3 个属于 N4 Pro。
- 未过滤时，Scene Shift 会切到空场景（动作数为 0），表现为旋钮“未绑定”。
- 重制版规则：
  1. 扫描 `profiles\*.sdProfile`；
  2. 读取每个场景 manifest 的 `DeviceUUID` / `DeviceSerialNumber`；
  3. 与当前设备匹配的场景加入“可用场景”列表；
  4. 按目录创建时间排序；
  5. Scene Shift 只在该列表内循环。

## 6. 页面模型

- 场景根页：`<场景UUID>.sdProfile\manifest.json`，资源在同一目录。
- 子页：`<场景UUID>.sdProfile\profiles\<页面UUID>.sdProfile\manifest.json`。
- 判断当前页是否为根页：页面 UUID 等于场景目录名（或不含子目录）→ 用根 manifest；否则进入 `profiles\<UUID>`。
- 切页动作：
  - 读取新页 manifest 的 `Actions`；
  - 重建动作表；
  - 整页刷新；
  - Control Bar 的滚动位置**保持**（官方行为，不重置）。
- 页码显示：`当前页 / 总页数`，日志与 Page Indicator 使用。

## 7. 图片资源引用

- 图片字段通常位于动作的 `States` 或 `Settings` 中（如 `image`、`path`、`file`），不同版本键名略有差异。
- 路径可能是绝对路径，也可能是相对当前页目录的相对路径。
- 重制版解析顺序：绝对路径 → 当前页目录相对路径 → 场景根目录相对路径。
- 图片可能为 PNG / JPG / GIF；静态取第一帧。

## 8. 已知配置陷阱

| 陷阱 | 说明 |
|---|---|
| 多设备场景混放 | 必须按 `DeviceUUID` 过滤 |
| 空 UUID 的 Scene Shift | 官方按方向循环切换场景；不能报错忽略 |
| 子页 `profiles` 嵌套 | 场景根目录下也有 `profiles` 文件，注意区分自身与子页 |
| `widgetCurrX` 为负 | 表示已向右滚动，恢复时取相反数并夹到 `[0, max]` |
| 图片缺失 | 回退官方内置图标（旋钮/翻页等），避免黑块 |
| 页面动作数差异 | 不同页面动作数不同（实测 11~16 个），切换后必须重建动作表 |

## 9. 未使用但已确认的配置能力（供新项目扩展）

- 背景层图片（BGPIC / BGCLE）。
- 旋钮 RGB（官方可配置，重制版按需求不加载）。
- 插件动作（Node 插件进程，重制版不加载）。
- 多状态动作图（按下/开启/关闭状态切换）。
- 触摸条 20+ 图标的虚拟长条（单张 800×130 + 横向滚动实现，非多张大图拼接）。

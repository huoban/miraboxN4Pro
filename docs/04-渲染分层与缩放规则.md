# 04 · 渲染分层、尺寸与缩放规则

> 本文覆盖背景层、图标层、文字层、触摸条布局、旋钮分区与图片缩放。
> 所有尺寸均为下发给设备的 PNG 像素尺寸。

## 1. 画布与目标尺寸

| 区域 | 尺寸 | 对应命令 |
|---|---|---|
| 按键 | **112 × 112** | `BAT`（下排 6~10 / 上排 11~15） |
| 触摸条（整体） | **800 × 130** | `BGPIC`（Control Bar / 背景） |
| 触摸条（分区） | 800 / 4 = **200 × 130** 每区 | `BAT`（槽位 1~4） |
| 上排按键槽位 | **11~15** | 输入 1~5，对应配置 `y2` |
| 下排按键槽位 | **6~10** | 输入 6~10，对应配置 `y1` |
| 槽位 5 | 未使用 | — |

- 触摸条在按键模式下按 4 个分区发送，旋钮模式下 4 个分区分别显示 4 个旋钮图标。
- 所有图像发送前 **旋转 180°**（按键与触摸条），否则真机上下颠倒。

## 2. 背景层

- 命令：`BGPIC`（800×130 PNG）与 `BGCLE`（清背景）。
- 官方 Control Bar 始终使用 **单张 800×130 图**，不是多张大图拼接。
- 背景层会覆盖按键层，因此刷新顺序必须是：
  ```
  CLE → 触摸条（BGPIC 或分区 BAT）→ 按键 BAT × 10 → SETLB → STP
  ```
- 只有 Control Bar 模式使用背景图；旋钮模式用分区图，不使用 BGPIC。

## 3. 图标层

### 3.1 按键

- 每个按键一张 112×112 PNG。
- 图标来源：动作 `States` / `Settings` 中的图片字段；缺失时使用内置回退图。
- 官方内置回退图标（旋钮/翻页）：
  - `btn_switchProfile_knob_N4pro.png`
  - `N4pro_btn_media_*`
  - `N4pro_btn_media_volume.png`
  - `N4pro_changePage{N}.png`

### 3.2 触摸条（Control Bar）

- 先绘制 800×130 画布，再按条目横向排布。
- 条目尺寸：**142 × 66**，纵向 Y = **42**。
- 起始 X = **25**，相邻步长 = **152**（即条目间空隙 10）。
- 虚拟总宽：`25 + (n-1) × 152 + 142`。
- 最大滚动：`25 + (n-1) × 152 + 142 - 780`（右侧留 20）。
- 两侧绘制返回箭头（`0x39` 区域）。
- 条目背景为圆角矩形，文字绘制在图标上方或下方（取决于配置）。

### 3.3 触摸条（旋钮模式）

- 4 个分区，每区 200×130。
- 每区显示当前页 `Actions["0,0"]`~`"3,0"` 对应旋钮的图标。
- 官方 `dialRotate` 只转发动作，不重绘触摸条；切页才重建。
- 图标缺失时回退内置图（场景切换 / 多媒体 / 音量 / 翻页）。

## 4. 文字层

- 文字不是设备字体，而是**主机侧 GDI `DrawTextW` 绘制进 PNG**。
- 字号换算：官方配置的单位按 **pt × 1.2 = 像素高** 处理（不是 96/72）。
  - 例：12pt → 约 14.4px；实际取整后按 GDI 逻辑单位绘制。
- 对齐：左/中/右 + 垂直居中；超长文本使用省略号（`DT_END_ELLIPSIS`）。
- 颜色：跟随配置（常见白色 / 黑色），绘制时启用透明背景（`SetBkMode(TRANSPARENT)`）。
- 字体：默认系统字体（微软雅黑/宋体），抗锯齿 `ANTIALIASED_QUALITY`。
- 文字层位于图标层之上；按键与触摸条分别绘制。

## 5. 缩放规则（重点）

官方 `SDActionCanvasLabel::getFixedProportionImage`（`0x1401223D0`）：

```cpp
QImage scaled = image.scaled(targetSize, Qt::KeepAspectRatio,
                             Qt::SmoothTransformation);
// 在透明画布（按键）或黑底画布（部分控件）上居中绘制
x = (targetW - scaled.width())  / 2;
y = (targetH - scaled.height()) / 2;
```

确认结论：

| 规则 | 结论 |
|---|---|
| 保持比例 | 是（KeepAspectRatio） |
| 裁剪 | 否（不裁切） |
| 小图是否放大 | **是**（官方真机小图标会放大填满，无“跳过缩放”分支） |
| 大图是否缩小 | 是 |
| 居中 | 是 |
| 平滑 | 是（SmoothTransformation） |
| 铺满裁剪 | 仅背景填充层使用 `scaledToFill`，图标不使用 |

重制版实现：`Canvas::draw_fit`——等比缩放完整放入并居中，**不跳过放大**，不裁剪。
实测素材尺寸跨度 31×30 ~ 886×411，均按此规则处理。

## 6. Control Bar 命中计算

官方 `getTouchbarLoactionFromX`（`0x1401A8210`）等价公式：

```
index = (X + scroll - 25) / 152
```

- `scroll` 为当前横向偏移（像素，≥0）。
- `X` 来自输入报文（800 坐标系）。
- 两侧箭头区域（X < 25 或 X > 780）不参与条目命中。
- 条目数无上限；滚动偏移持久化在 `Actions.touchbar.Settings.widgetCurrX`（负值）。

## 7. 旋钮图标与页面绑定

- 图标来源：当前页 `Actions["0,0"]`~`"3,0"`。
- 切页后必须重新加载动作表并重发 1~4 区图。
- 旋钮按下/旋转都执行该位置绑定的动作。
- Scene Shift 的 `ProfileUUID` 为空时，按方向循环切换“本设备可用场景”。

## 8. 编码与缓存

- 解码：PNG / JPG / GIF（GIF 取第一帧）。
- 缩放后重新编码 PNG，按 1024 字节分片。
- 缓存策略：
  - 以“图片路径 + 目标尺寸 + 是否旋转”为键缓存 PNG 字节；
  - 切页时清空动作表相关缓存；
  - 同一页重复按键不重新编码。
- 单张 PNG 建议 < 64KB，避免整页刷新帧数过多（实测整页 177~385 帧）。

## 9. 常见渲染问题对照

| 现象 | 原因 | 正确做法 |
|---|---|---|
| 图标被拉伸变形 | 使用 cover 铺满后裁剪 | 等比 contain + 居中 |
| 小图标显示很小、四周黑边 | 跳过放大 | 小图也等比放大 |
| 真机上下颠倒 | 未旋转 180° | 发送前统一旋转 |
| Control Bar 第 6 个图标缺失 | 最大滚动算小 | `25+(n-1)*152+142-780` |
| 滑动不跟手 | 每帧整页重绘 | 滑动只发 800×130 一张图，30~60ms 节流 |
| 文字偏大 | 按 96/72 换算 | 按 `pt × 1.2` |
| 触摸条文字镜像 | 未做整条 180° 预旋转 | 整条旋转后再叠加文字层 |

## 10. 未使用但已确认

- 背景层（BGPIC/BGCLE）在重制版中仅 Control Bar 使用。
- 旋钮 RGB 灯效：官方可配置，重制版按需求不加载。
- 动画帧（GIF/多帧）：官方支持，重制版当前取首帧。
- 多状态图（按下/开启）：官方支持，重制版当前按静态图处理。

# 05 · 动作体系与 Settings 字段字典

> 动作由动作节点 `UUID` 决定类型，参数在 `Settings` 中。
> 标注「推断」的字段名来自官方命名习惯，接入新项目时建议先用真实配置核对。

## 1. 分派顺序（重制版实现）

```
UUID 命中插件 → 跳过（不启动 Node 插件）
profile.rotate        → 场景切换
page.change           → 上一页 / 下一页
http                  → HTTP 请求
osc                   → OSC/UDP
network.udp / system.udp → UDP
website               → 打开网址
system.open / *.open  → 打开文件/程序
multimedia            → 多媒体键
volume                → 音量键
delay                 → 等待
multiactions          → 操作流（多动作）
hotkey                → 热键
system.close          → 退出程序动作（重制版忽略）
其它                  → 记录“未识别动作”并忽略
```

- 插件类动作不加载插件进程（需求约定）。
- 未识别动作不能导致程序崩溃或卡死。

## 2. 热键 Hotkey

| 字段 | 类型 | 说明 |
|---|---|---|
| `VKeyCodes` | number[] | 主键虚拟键码列表，可多主键同时按下 |
| `KeyCtrl` / `RKeyCtrl` | bool | 左 / 右 Ctrl |
| `KeyShift` / `RKeyShift` | bool | 左 / 右 Shift |
| `KeyAlt` | bool | 旧字段；实际 Alt 在 `KeyOption` |
| `KeyOption` | bool | **Alt（已确认）** |
| `RKeyOption` | bool | 右 Alt（推断） |
| `KeyWin` / `RKeyWin` | bool | 左 / 右 Win |
| `executionTimes` | number | 重复执行次数 |
| `Coalesce` | bool | 连续触发时合并（推断） |

发送规则（已实机验证）：

- 使用 **扫描码** `SendInput`（`KEYEVENTF_SCANCODE`，扩展键加 `EXTENDEDKEY`）。
- 左右修饰键分别发送：L-Ctrl `0xA2`、R-Ctrl `0xA3` 等。
- 顺序：修饰键按下 → 主键按下 → 15~18ms → 释放。
- 不要使用无扫描码的 `keybd_event`，部分程序/游戏会漏键。

## 3. Super Hotkeys / Hotkey Switch

- Super Hotkeys：扫描码模拟物理按键 + `executionTimes` 重复 + `openShowState`（等待窗口就绪）。
- Hotkey Switch：多组热键轮换，执行后切换到下一组状态。
- 与普通 Hotkey 共用同一发送实现。

## 4. 鼠标事件 Mouse event（已逆向确认）

### 4.1 Settings 字段（按键）

| 字段 | 说明 |
|---|---|
| `mouseEventIndex` | 事件类型：0 单击 / 1 双击 / 2 移动 / 3 滚轮 / 4 拖拽 |
| `mouseButtonIndex` | 按键：0 左 / 1 右 / 2 竖向滚轮 / 3 横向滚轮 / 4 侧键1 / 5 侧键2 |
| `mouseRadioButtonIndex` | 附加按键选择（含义待确认，当前实现未使用） |
| `xCoordinate` / `yCoordinate` | 起始/目标坐标（绝对屏幕坐标，整数） |
| `xCoordinateDest` / `yCoordinateDest` | 拖拽终点坐标 |
| `amountOfWheelMovement` | 滚轮量（带符号） |
| `openModifier` | 是否启用修饰键 |
| 修饰键 | 与热键相同的 `KeyCtrl` / `RKeyCtrl` 等字段 |

### 4.2 Settings 字段（旋钮）

| 字段 | 说明 |
|---|---|
| `mouseEventIndexKnob` | 旋钮事件：0 单击 / 1 双击 / 3 滚轮（推断随主事件枚举） |
| `mouseButtonIndexKnob` | 旋钮按键（滚轮/侧键） |
| `xCoordinateKnob` / `yCoordinateKnob` | 旋钮鼠标坐标 |
| `amountOfWheelMovementknob` | 旋钮滚轮量（注意是小写 `knob`） |

### 4.3 枚举来源

- 官方主程序内嵌语言表：`鼠标单击/鼠标双击/鼠标移动/鼠标滚轮/鼠标拖拽`、`左键/右键/竖向滚轮/横向滚轮/侧键1/侧键2`。
- 反汇编下拉框构建函数（`0x1400DF0F0`）确认 5 项事件的顺序。
- 旋钮按下仅“单击/双击”两项。

### 4.4 执行语义

- 单击/双击：定位 → 修饰键按下 → 鼠标按下/抬起（双击两次）→ 修饰键释放。
- 移动：绝对坐标移动。
- 滚轮：按 `amountOfWheelMovement` 正负发送竖向/横向滚轮。
- 拖拽：起点按下 → 移动到终点 → 抬起。
- 进程需 Per-Monitor/System DPI 感知，保证坐标与官方一致。

## 5. 操作流 Multi Actions

| 字段 | 说明 |
|---|---|
| `Actions` | 子动作数组 |
| `Settings.delay`（子动作） | **执行该子动作前等待的毫秒数**（实测 800/1000/230000） |
| `enablingCycle` | 是否启用循环 |
| `cycleMode` | 循环模式（次数/无限，推断） |
| `cycleNumber` | 循环次数 |
| `cycleDelay` | 循环间隔毫秒 |

变体（按 UUID 区分）：

| 类型 | 行为 |
|---|---|
| 多动作 routine | 顺序执行，每个子动作前等待其 delay |
| Delay | 等待 `delay` 毫秒 |
| Action Carousel | 每次触发执行下一个子动作（索引持久化） |
| Action Cycle | 每次触发在两套子动作间切换 |
| ActionWheel | 旋钮旋转按步进执行对应子动作 |
| ActionTrigger | 旋钮按下/长按触发 |

- 支持嵌套；实现需限制递归深度。
- 子动作可以是任意基础动作（热键、鼠标、延时、打开等）。

## 6. 页面与场景

| UUID 片段 | 字段 | 行为 |
|---|---|---|
| `page.change` | `Next`（bool） | true 下一页 / false 上一页 |
| `page.goto` | 页面 UUID（推断） | 跳转指定页 |
| `profile.rotate` | `ProfileUUID` | 非空切换指定场景；为空按方向循环切换本设备场景 |
| `profile.back` | 无 | 返回根页 |
| `profile.child` | 场景 UUID（推断） | 进入子场景 |

## 7. 多媒体与音量

多媒体 `actionIdx`（已确认部分）：

| 编号 | 功能 |
|---|---|
| 0 | 播放/暂停 |
| 1 | 下一曲 |
| 2 | 上一曲 |
| 3 | 停止 |
| 4 | 静音 |
| 5 | 音量加 |
| 6 | 音量减 |
| 22 | 播放/暂停（官方配置实测） |

音量 `actionIdx`：0 静音 / 1 音量加 / 2 音量减。

- 旋钮旋转时：多媒体按方向发送上一曲/下一曲，音量按方向加减；按下执行配置的编号。

## 8. 工具箱类

| 动作 | 关键字段 | 说明 |
|---|---|---|
| Open | `path` | 打开文件/文件夹 |
| Open APP | `path` / `args` | 启动程序并传参 |
| Close | `target`、`forceOut` | 关闭窗口/进程，`forceOut` 为强制结束 |
| Text | `text`、输入方式、`isSendingEnter` | 剪贴板粘贴或逐字输入 |
| Password | 同 Text | 值来自配置 |
| Website | `url` | 默认浏览器打开 |
| Brightness | 目标亮度/步进 | 按键循环档位，旋钮增减 |
| devsleep | 无 | 设备息屏 |

## 9. 音频播放器（Soundboard）

| 字段 | 说明 |
|---|---|
| `actionType` | 播放/停止 |
| `fadeType` / `fadeDuration` | 淡入淡出类型与时长 |
| `outputType` / `volume` | 输出设备与音量 |
| 文件路径 | 兼容 `path` / `audioPath` / `soundPath` / `filePath` |
| `actionIdx` | 播放/停止编号 |

- 实现：MCI（wav/mp3），播放中可切换按键状态图。
- Stop Audio：停止全部播放。

## 10. 切换音频设备

| 字段 | 说明 |
|---|---|
| `radio` | 播放/录音类型 |
| `device` / `select` / `select2` | 目标设备名/ID |
| 状态图 | 4 个状态图标 |

- 实现：Core Audio `IPolicyConfig::SetDefaultEndpoint`（未公开接口，需按系统版本回退）。

## 11. 触控条内置动作（Windows 可用项）

通知中心、截图、输入法、显示桌面、锁屏、睡眠、语音识别、屏幕亮度、媒体键、音量/静音、勿扰（按官方默认热键）。

- macOS 专属（Siri、Launchpad、调度中心等）跳过并记录日志。
- 屏幕亮度在 Windows 无通用接口，当前跳过。

## 12. 延时与等待

- `delay`：等待 `Settings.delay` 毫秒。
- 多动作子项：等待其 `Settings.delay` 后再执行。
- 230 秒级延时来自用户配置，必须原样支持，不能截断。

## 13. 插件与未实现动作

- `com.mirabox.*`、`com.streamdock.*`、OBS/vMix/YouTube 等插件：不加载，记录后跳过。
- `plain.text`（副屏文本）、`mouse.event` 之外的插件 UI：未适配。
- `system.close`：重制版不提供退出按钮，忽略。
